# 🏨 Royal Hotel Management System

Информационная система управления отелем «Royal Hotel». Позволяет автоматизировать процессы заселения, управления номерным фондом, контроля работы персонала и анализа выручки.

## 🚀 Основные возможности

-   **Dashboard (Управление номерами):** Визуализация статуса номеров (свободен/занят/грязный), быстрое заселение гостей.
-   **Журнал гостей:** Полный список активных постояльцев, поиск по паспорту и печать счетов (Invoice).
-   **Персонал и Уборка:** Назначение заданий на уборку конкретных номеров или целых этажей, контроль статуса сотрудников.
-   **Аналитика:** Мониторинг выручки, загрузки отеля и оперативных задач.
-   **Архив:** История всех завершенных проживаний.
-   **Администрирование:** Редактирование базы номеров и штата сотрудников.

## 🛠 Технологический стек

### Frontend
- **React + Vite** (быстрая сборка и высокая производительность)
- **Tailwind CSS** (современный адаптивный дизайн)
- **Lucide React** (набор иконок)
- **Axios** (взаимодействие с API)
- **Vitest** (юнит-тестирование фронтенда)

### Backend
- **Node.js + Express** (серверная логика)
- **PostgreSQL** (надежное хранение данных)
- **Jest + Supertest** (комплексное тестирование бэкенда)

## ⚙️ Установка и запуск

### 1. Подготовка базы данных
Создайте базу данных в PostgreSQL и выполните SQL-запрос для создания таблиц (пример структуры):
- `rooms` (номера, этажи, статус уборки)
- `clients` (ФИО, паспорт, даты заезда)
- `employees` (персонал, статусы)
- `cleaning_schedule` (график работ)

### 2. Настройка бэкенда
```bash
cd server
npm install
```
Создайте файл `.env` в папке `server`:
```env
DB_USER=your_user
DB_PASSWORD=your_password
DB_HOST=localhost
DB_PORT=5432
DB_DATABASE=hotel_db
```
Запуск сервера:
```bash
node index.js
```

### 3. Настройка фронтенда
```bash
cd client
npm install
npm run dev
```

## 🧪 Тестирование

В проекте реализовано более 25 юнит-тестов, покрывающих критическую бизнес-логику.

### Тестирование бэкенда (Jest)
Проверяется расчет стоимости проживания, валидация паспортных данных, логика распределения задач по уборке и аналитические отчеты.
```bash
cd server
npm test
```

### Тестирование фронтенда (Vitest)
Проверяется корректность отображения UI-компонентов, фильтрация списков и расчет процентов загрузки отеля.
```bash
cd client
npm test
```
